# MeldNexus

MeldNexus is an Artificial Intelligence-driven, multi-threaded Manager for asynchronous data processing and event-driven System orchestration.

MeldNexus is built to be simple and practical, focusing on doing one thing well.

**Why MeldNexus?**

- MeldNexus is an Artificial Intelligence-driven,
- multi-threaded Manager for asynchronous data
- processing and event-driven System orchestration

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/MeldNexus.git`
2. `cd MeldNexus`
3. Install in editable mode: `pip install -e .`

## Configuration

MeldNexus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
